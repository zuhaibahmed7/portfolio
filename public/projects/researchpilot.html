Overview

ResearchPilot is a multi-agent AI reasoning system built for the Microsoft Agents League Hackathon (Reasoning Agents track). It autonomously decomposes research questions, retrieves sourced evidence, self-critiques coverage, and synthesizes structured reports with citations.

Architecture

The system uses a 4-agent pipeline:

  • Planner — Decomposes complex research questions into sub-questions
  • Researcher — Retrieves sourced evidence for each sub-question
  • Critic — Evaluates coverage and triggers re-research when confidence falls below threshold
  • Synthesizer — Combines findings into a structured report with citations

Key Features

  • Self-critique re-research loop — the Critic agent detects knowledge gaps and triggers additional research
  • Real-time web frontend using FastAPI + Server-Sent Events (SSE) streaming live pipeline progress
  • Built on GitHub Models free inference endpoint (GPT-4o/GPT-4o-mini)
  • Deployed on Hugging Face Spaces via Docker
