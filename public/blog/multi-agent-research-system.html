How I Built a Multi-Agent Research System with LLMs

August 27, 2026 · 8 min read

Most AI tools today are single-prompt wrappers — you ask a question, you get an answer. But what if the AI could plan its own research, critique its own work, and fill in the gaps automatically? That's what I set out to build with ResearchPilot.

The Problem with Single-Prompt AI

When you ask a language model a complex research question, it gives you one shot. If it misses something, you have to rephrase and try again. There's no self-reflection, no quality control, and no systematic coverage.

The Architecture: 4 Agents, 1 Pipeline

ResearchPilot uses four specialized agents working together:

1. Planner Agent

Takes a complex research question and decomposes it into focused sub-questions. Think of it as creating a research outline before diving in.

2. Researcher Agent

Takes each sub-question and retrieves evidence from the web. It searches, reads, and extracts relevant information with source citations.

3. Critic Agent

This is where it gets interesting. The Critic evaluates the research quality and coverage. If it finds gaps or low-confidence areas, it triggers additional research rounds.

4. Synthesizer Agent

Combines all findings into a structured report with proper citations and confidence scores.

The Self-Critique Loop

The key innovation is the feedback loop between Researcher and Critic:

Researcher → produces evidence
Critic → evaluates quality
  ↓ (if confidence < threshold)
Researcher → re-researches gaps
  ↓ (repeat until confident)
Synthesizer → final report

This means the system doesn't just accept the first answer — it actively seeks to improve its own output.

Tech Stack

  • Backend: Python + FastAPI with Server-Sent Events for real-time streaming
  • LLM: GitHub Models free inference (GPT-4o/GPT-4o-mini via OpenAI SDK)
  • Frontend: React with live pipeline progress visualization
  • Deployment: Docker on Hugging Face Spaces

Key Takeaways

  • Multi-agent systems are more reliable than single-prompt approaches for complex tasks
  • Self-critique loops dramatically improve output quality
  • The Planner agent is crucial — good decomposition leads to better research
  • Real-time streaming makes the system feel alive and builds trust
ResearchPilot was built for the Microsoft Agents League Hackathon (Reasoning Agents track). It's open source and available on Hugging Face Spaces.
