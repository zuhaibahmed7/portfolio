Overview

AgroVision is an end-to-end AI web application that predicts plant diseases from leaf images. It uses a Convolutional Neural Network (CNN) trained on over 54,000 leaf images across 38 disease classes, achieving 88% validation accuracy and 98% training accuracy.

How It Works

  • Upload a photo of a plant leaf through the Streamlit interface
  • Image is preprocessed (224x224 resize, normalization)
  • CNN model predicts the disease class with confidence score
  • Results displayed instantly with disease information

Technical Details

  • Model: Custom CNN architecture trained on PlantVillage dataset
  • Dataset: 54,305 images across 38 classes (healthy + diseased)
  • Training: 98% training accuracy, 88% validation accuracy
  • Interface: Interactive Streamlit web app
  • Deployment: Containerized with Docker for reproducible environments

Supported Crops

The system can identify diseases across multiple crop types including apple, blueberry, cherry, corn, grape, orange, peach, pepper, potato, raspberry, soybean, squash, strawberry, and tomato.
