Plant diseases cost the global agriculture industry billions of dollars annually. Early detection is critical, but most farmers don't have access to plant pathologists. I built AgroVision to bridge this gap — an AI system that identifies plant diseases from a simple photo.

The Dataset

I used the PlantVillage dataset — 54,305 images of plant leaves across 14 crop species and 38 disease classes (including healthy). The images are already segmented (background removed) and standardized to 256x256 pixels.

Model Architecture

I trained a custom CNN with the following architecture:

Input (224x224x3)
  → Conv2D(32, 3x3) + ReLU + MaxPool
  → Conv2D(64, 3x3) + ReLU + MaxPool
  → Conv2D(128, 3x3) + ReLU + MaxPool
  → Conv2D(256, 3x3) + ReLU + MaxPool
  → Flatten → Dense(512) → Dropout(0.5)
  → Dense(38, softmax)

Training Results

  • Training accuracy: 98% after 25 epochs
  • Validation accuracy: 88% (good generalization)
  • Loss convergence: Stable after epoch 15

Building the Interface

I chose Streamlit for the web interface because it's perfect for ML demos:

  • Upload a leaf photo (drag & drop or camera)
  • Image is preprocessed (224x224 resize, normalization)
  • Model predicts disease class with confidence score
  • Results displayed instantly with disease information

Deployment with Docker

The entire app is containerized with Docker for reproducibility:

FROM python:3.10-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 8501
CMD ["streamlit", "run", "app.py"]

Lessons Learned

  • Data quality matters more than model complexity — the PlantVillage dataset's clean segmentation made a huge difference
  • Data augmentation (rotation, flip, zoom) helped prevent overfitting
  • The biggest challenge was class imbalance — some diseases had far fewer samples
  • Streamlit made the demo accessible to non-technical users
AgroVision is designed to help farmers in developing countries where access to plant pathologists is limited. The system works offline once deployed, making it suitable for areas with limited internet connectivity.
